# Portfolio App (Desafio React Native | DIO) Formação React Native Developer

Aplicativo mobile de portfólio pessoal desenvolvido em **React Native**, **Expo** e **TypeScript**, com navegação entre telas 
utilizando **React Navigation (`@react-navigation/native-stack`)**. Para a formação **Formação React Native Developer*.

---
## 🙏 Agradecimentos

Este projeto foi desenvolvido com base nas aulas e orientações do professor **Felipe Aguiar**. Conheça mais sobre o trabalho dele em seu perfil no GitHub: [@felipeAguiarCode](https://github.com/felipeAguiarCode).

---

## 🚀 Tecnologias Utilizadas

* **React Native** com **Expo**
* **TypeScript**
* **React Navigation** (`@react-navigation/native` e `@react-navigation/native-stack`)
* **React Native Linking** para abertura de links externos

## 📱 Funcionalidades

* **MainScreen:** Exibe foto de perfil, nome, botões de acesso rápido para **LinkedIn** e **GitHub**, botão de **E-mail** e botão de navegação para a árvore de habilidades.
* **SkillScreen:** Exibe foto de perfil, nome e uma árvore organizada de habilidades separada entre **Front-end** e **Back-end** com níveis indicativos e retorno para a tela anterior.

🛠️ Como Executar o Projeto
Clone este repositório:

Bash
`git clone [https://github.com/HigorCamposGit/Portfolio-App-React-Native.git](https://github.com/HigorCamposGit/Portfolio-App-React-Native.git)`
Entre na pasta do projeto:

Bash
`cd Portfolio-App-React-Native`
Instale as dependências:

Bash
`npm install`
Inicie o servidor do Expo:

Bash
`npx expo start`
Abra no aplicativo Expo Go ou emulador.
